# Boise expansion validation

The Boise Development Tracker is an early-lead planning source. Boise records are stored with `stage=PLANNING` and must not be promoted as qualifying new construction when the project narrative indicates conversion or modification work.

Regression guards cover:
- a bare duplex planning application remains a qualifying multifamily early lead;
- conversion of an existing triplex to duplex with exterior modifications is suppressed;
- the Boise collector continues to map the official Development Tracker record shape into the shared Idaho permit model.
